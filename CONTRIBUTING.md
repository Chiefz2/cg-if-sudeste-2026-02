# Guia de Colaboração — Computação Gráfica (2026/02)

Contribuições da turma com resoluções de laboratórios, anotações e novos exemplos em OpenGL/FreeGLUT são bem-vindas, desde que sigam as regras de organização abaixo.

## Regra Principal: Preservação do Material Original
* Nunca altere, renomeie ou exclua os arquivos PDF da raiz nem os códigos originais dentro da pasta Exemplos/.
* Todo material enviado pelo professor deve permanecer intacto para consulta de todos.

## Como Enviar Exercícios ou Resoluções
1. Faça um Fork deste repositório para a sua conta do GitHub.
2. Crie uma pasta dedicada às suas resoluções seguindo o padrão Resolucoes/SeuNomeOuUsuario/ (exemplo: Resolucoes/JoaoSilva/Lab01.cpp).
3. Certifique-se de que o seu código compila sem erros no GCC/G++ com FreeGLUT e não inclua arquivos executáveis (.exe ou binários Linux) no envio.
4. Faça o commit das suas alterações e abra um Pull Request detalhando qual exercício ou laboratório está sendo adicionado.
